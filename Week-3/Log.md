This week I was in Group B, so I worked in the GIS lab and also followed week 4's instructions as well as the readings. This week I also reviewed the feedback emails about these weekly entries to try to improve them. 

What I tried this week: 
- Used QGIS and loaded the Ontario shapefiles provided to us
- Familiarized myself with QGIS
- Looked at vector and raster layers within QGIS, like how to add them and modify them
- Learnt how to use the buffer and clip tools for geoprocessing
- Also learnt how to project layers 

Errors encountered 
- QGIS is hard and confusing to use; luckily, I have some experience with mapping software like ARCGIS
- It is difficult to start using a new mapping software after using others
- Most errors encountered in the Lab came from stuff like putting in the wrong input later and overlaying layers while trying to clip or buffer something.
